REASONS FOR ALLOWANCE
The following is an examiner’s statement of reasons for allowance:
The prior art does not teach or suggest “in response to a determination that the rate of change metric exceeds the first threshold, that the sum of analyte levels metric exceeds the second threshold, and that a difference between the first time and the second time is less than a predetermined time threshold, generate an indication of a sensor fault.”.
Regarding claim 1, the closest prior art, US 20160022221 A1 (Hereinafter Ou) (previously cited), teaches an analyte monitoring system, comprising: a sensor control device including an analyte sensor at least a portion of which is configured to be inserted into a user's body ([0017], “the present disclosure is operable to identify sensor faults from data from an in vivo analyte sensor.”), first processing circuitry ([0021], “The computer system may include one or more processors for executing instructions or programs”), and a first non-transitory memory ([0021], “The computer system may include memory and persistent storage devices to store and manipulate the instructions and sensor data received from the analyte monitoring system.”), wherein the sensor control device is configured to collect sensor data indicative of an analyte level from the analyte sensor ([0017], “The present disclosure provides systems, methods, and apparatus to identify sensor fault modes using sensor data from an analyte monitoring system”); and a reader device ([0021], “may be embodied as a handheld or portable receiver unit within the analyte monitoring system.) comprising second processing circuitry comprising second processing circuitry ([0021], “The computer system may include one or more processors for executing instructions or programs”) and a second non-transitory memory ([0021], “The computer system may include memory and persistent storage devices to store and manipulate the instructions and sensor data received from the analyte monitoring system.”), wherein at least one of the first or the second non-transitory memory includes instructions that, when executed, cause the at least one of the first or the second processing circuitry to: calculate a rate of change metric based on the collected sensor data wherein the rate of change metric is calculated at a first time ([0019], “When sensor data obtained over a window of time is first obtained, a baseline pair can be calculated. a baseline analyte variability value is computed from this dataset.”; [0035], “the datasets should not overlap in time”; The first-time window is a first time.); calculate a sum of analyte levels metric based on the collected sensor data, wherein the sum of analyte levels metric is calculated at a second time ([0028], “Based on this first dataset, a baseline median glucose value is computed. Alternatively, a mean, a mode, or any other representative “static” value of the first dataset may be used”; [0035], “Based on this new dataset, an evaluation median glucose value is computed (714).” The second time is the time in which the second dataset is obtained. The sum is then calculated as alternative to the median as discussed in [0028]); compare the rate of change metric with a first threshold ([0019], “The component of the vector is compared to a predetermined threshold value”) and compare the sum of analyte levels metric with a second threshold ([0032], “The system may then compare the sensor output to reference glucose measurement(s) relative to a second threshold”); and in response to a determination that the rate of change metric exceeds the first threshold, that the sum of analyte levels metric exceeds the second threshold, generate an indication of a sensor fault ([0031], “If the component is larger than the threshold value, the system alerts the user that a fault has occurred or that the end of the sensor's life has been detected”).
Ou does not teach or suggest that an indication of a sensor fault is generated when a difference between the first time and the second time is less than a predetermined time threshold.
Claims 2-11 are allowable by virtue of their dependence from claim 1.
Regarding claim 13, Ou teaches a computer-implemented method for detecting a sensor fault, ([0005], “Some embodiments of the present disclosure include computer-implemented methods of identifying sensor fault modes using analyte monitoring system sensor data”) the method comprising: collecting, by a sensor control device comprising an analyte sensor at least a portion of which is inserted into a user's body sensor data indicative of an analyte level ([0017], “the present disclosure is operable to identify sensor faults from data from an in vivo analyte sensor.”); calculating a rate of change metric based on the collected sensor data wherein the rate of change metric is calculated at a first time ([0019], “When sensor data obtained over a window of time is first obtained, a baseline pair can be calculated. a baseline analyte variability value is computed from this dataset.”; [0035], “the datasets should not overlap in time”; The first-time window is a first time.); calculating a sum of analyte levels metric based on the collected sensor data, wherein the sum of analyte levels metric is calculated at a second time ([0028], “Based on this first dataset, a baseline median glucose value is computed. Alternatively, a mean, a mode, or any other representative “static” value of the first dataset may be used”; [0035], “Based on this new dataset, an evaluation median glucose value is computed (714).” The second time is the time in which the second dataset is obtained. The sum is then calculated as alternative to the median as discussed in [0028]); comparing the rate of change metric with a first threshold ([0019], “The component of the vector is compared to a predetermined threshold value”) and comparing the sum of analyte levels metric with a second threshold ([0032], “The system may then compare the sensor output to reference glucose measurement(s) relative to a second threshold”); and in response to determining that the rate of change metric exceeds the first threshold and that the sum of analyte levels metric exceeds the second threshold, generating an indication of a sensor fault ([0031], “If the component is larger than the threshold value, the system alerts the user that a fault has occurred or that the end of the sensor's life has been detected”).
Ou does not teach that an indication of a sensor fault is generated when a difference between the first time and the second time is less than a predetermined time threshold.
Claims 14-16 and 18-20 are allowable by virtue of their dependence from claim 13.
