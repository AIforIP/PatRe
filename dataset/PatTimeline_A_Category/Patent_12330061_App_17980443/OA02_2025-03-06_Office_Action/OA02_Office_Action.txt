REASONS FOR ALLOWANCE
The following is an examiner’s statement of reasons for allowance: The closest prior art is Huang (Chinese patent publication CN 111659117 A, cited on the IDS, see NF, 10-01-2024, pages 13 to 15).  Huang discloses a virtual object display method and device, a computer device, and a storage medium (see description, Paras. 2 to 46, and abstract): displaying a virtual scene picture (i.e. displaying the display picture of the virtual environment), the virtual scene picture being a picture obtained by observing a virtual scene at a visual angle of a first virtual object; and in response to that a second virtual object in the first virtual scene picture is in a target state (i.e. the target virtual object in the virtual environment), displaying a second virtual scene picture, the second virtual scene picture comprising the first virtual object and the second virtual object, the transparency of the second virtual object being positively correlated with the object distance, and the object distance being the distance between the first virtual object and the second virtual object (i.e. in response to the change of the relative position, adjusting the transparency of the position prompt mark).  Huang in particular does not suggest the increasing and decreasing of the transparency in relation to the distance as cited in the last two clauses of Claim 1 on conjunction with the rest of the claim limitations.
The present claims pertain to: “a mark processing method, performed by a computer device, the method comprising: displaying an aiming prompt mark on a display picture of a virtual environment, the aiming prompt mark being used for indicating a target aimed position at which a target virtual object in the virtual environment aims using a virtual weapon; displaying a position prompt mark on the display picture of the virtual environment according to a ”  The present claims have the overall advantage of making the target acquisition more intuitive and ergonomic over typical prior art games.  The examiner respects that the applicants may have different reasons for allowance.
