Allowable Subject Matter
The following is an examiner’s statement of reasons for allowance: Chen (U.S. 2012/123222) in view of Zaleski (U.S 7,945,457) have been identified as some of the most relevant prior art. However, the prior art fails to teach the combination of: providing, with a first software, an option in a first graphical user interface presented on a display for a user to select a determination of a health parameter that is specific to the second software; selecting the second software for the determination of the health parameter; receiving an indication that the second software was selected from the option in the graphical user interface; enabling the second software to execute the one or more post-processing functions on the determined one or more physiological parameters based on the selection of the second software, wherein the one or more post-processing functions are configured to determine the health parameter; and displaying, on a second graphical user interface, the health parameter on a display along with the one or more physiological parameters determined by the first software, wherein the second graphical user interface is generated by the first software; as required by claim 16. Furthermore, nothing of the record would suggest to one of ordinary skill in the art to modify the known prior art to arrive at the claimed invention.
