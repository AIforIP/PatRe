REASONS FOR ALLOWANCE
The following is an examiner’s statement of reasons for allowance: The closest prior art is Liu (Chinese patent publication CN 110755841 A, cited on the IDS and the ISR for the parent PCT case).  Liu discloses prop switching in a virtual environment, the method comprising wherein the first environment interface comprises a picture for observation of the virtual environment from the perspective of observation of a target virtual object, the target virtual object is in a first holding state for a first prop, and the first prop is a range attack prop; when the target virtual object is under an attachment attack performed by an enemy virtual character, displaying a second environment interface, wherein the second environment interface comprises a picture for observation of the virtual environment from the perspective in which the target virtual object is attacked, a target body position of the target virtual object is attached by the enemy virtual character, and the enemy virtual character is attached to the target body position to perform a melee attack on the target virtual object; and switching the first holding state of the target virtual object for the first prop to a second holding state of the target virtual object for a second prop, wherein the second prop is a melee attack prop (see Liu, description, Paras. 42 to 103, Figs. 1 to 17).  Liu is basically disclosing switching from a range attack prop such as a firearm to a melee weapon (second virtual object) such as a sword, ax, or knife.  It does not suggest the presently claimed predetermined motion path of the second virtual object in conjunction with the rest of the limitations as claimed.
The claims are drawn to: “a method of controlling a virtual object in a virtual scene performed by a computer device, the method comprising: displaying a virtual scene picture including a first virtual object and a second virtual object, the first virtual object including a first body part equipped with a first virtual prop and a second body part equipped with a second virtual prop and the second virtual object being located within an action range of a target action performed by the first virtual object; in response to receiving a first trigger operation on a target control of the first virtual object, controlling the first virtual object to perform the target action against the second virtual object based on the first virtual prop equipped at the first body part of the first virtual object and displaying a launch of the first virtual prop from the first body part towards the second virtual object along a predefined motion path of the first virtual prop; and in response to receiving a second trigger operation on the target control of the first virtual object within a specified duration after the first trigger operation is received, displaying a retract of the first virtual prop back to the first body part; and after the first virtual prop resumes its original position at the first body part, controlling the first virtual object to perform the target action against the second virtual object based on the second virtual prop equipped at the second body part of the first virtual object and displaying a launch of the second virtual prop from the second body part towards the second virtual object according to a predefined motion path of the second virtual prop.”
The presently claimed invention generally pertains to a game application with virtual props, such as a first-person shooting game, in which a melee virtual weapon used for melee combat may be included.  The melee virtual weapon is typically a single-handed melee virtual weapon.  When a target object is attacked through the single-handed melee virtual weapon, it is necessary to wait for the melee virtual weapon to be folded before a next attack is performed (essentially waiting for the target to let its guard down).  However, the typical prior art solution of attacking the target object through the single-handed melee virtual weapon makes interaction efficiency lower when a user controls a virtual object to attack.  The presently claimed invention has the overall advantage of providing a virtual object control method and apparatus which can improve interaction efficiency when a virtual object is controlled to perform interaction.  See Fig. 3, Paras. 70 to 88, especially Para. 88 of the specification.  The examiner respects that the applicant may have different reasons for allowance.
