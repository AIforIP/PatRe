REASONS FOR ALLOWANCE
The following is an examiner’s statement of reasons for allowance: The closest prior art is Lian (Chinese patent publication CN 110721469 A, cited on the IDS, see NF 10-01-2024, pages 13 to 15).  Lian discloses a method for shielding a virtual object in a virtual environment (Paras. 44 to 71, Figs. 1 & 2): a first user uses a first terminal to control a first virtual object in a virtual environment to perform activity, the activity comprising: crawling, using a virtual prop to harm other virtual objects, etc.; the user controls the virtual object to take a cover prop out of a backpack for equipping the cover prop; the cover prop shields the virtual object in a shielding direction when the cover prop is equipped; when the user controls the virtual object to attack a hostile virtual object, the cover prop has a defensive function and can help the virtual object to defend against the attack of the hostile virtual object (equivalent to in response to an equipment operation on a virtual cover prop, displaying the virtual cover prop at a first position of a controlled virtual object in a virtual scene, the virtual cover prop being used for shielding the controlled virtual object); when a movement operation on the virtual object is received, the cover prop and the virtual object are controlled to move in a same direction (equivalent to displaying that the virtual cover prop moves with the controlled virtual object).  Lian does not suggest the motion of the virtual shelter prop as claimed on conjunction with the other claim limitations (see the eighth and ninth clauses of Claim 1).
In the presently claimed invention, a controlled virtual object (such as a protagonist in a first-person shooter game) is sheltered by equipping the controlled virtual object with a movable virtual shelter prop (such as a riot shield or a ballistic shield used by soldiers or SWAT officers), so as to avoid the controlled virtual object being directly exposed in a virtual scene and being attacked by other virtual objects.  Position adjustment through various movement operation instructions can be avoided, thereby avoiding generating redundant data processing procedures and reducing waste of resources.  The virtual shelter prop is capable of moving with the controlled virtual object.  When the controlled virtual object runs, jumps, etc., the virtual shelter prop may also play a role in defending against an attack, thereby effectively improving the security of the controlled virtual object in competitive battles and improving the user experience.  The examiner respects that the applicants may have different reasons for allowance.
