The following is an Examiner’s Statement for reasons for allowance. None of the references of record either alone or in combination teaches or suggest the following limitations as claimed in claim 1, A system for a vehicle, comprising: a non-transitory memory component storing software components and comprising: a first memory space storing a first software component, a proxy software component, and an activity monitor software component; and
a second memory space storing a second software component and a stub software component, the first software component configured to interact with the second software component via the proxy software component and the stub software component; and at least one processor for executing software components stored on the first and second memory spaces such that the first software component is configured to perform a polling event of a sensor component stored in the first memory space to obtain a speed reading of the vehicle, perform a comparison event to compare the speed reading to a target speed, generate a command for engine output torque based on the comparison, and send the command to the proxy software component as a command event, and the proxy software component is configured to send the command event to the stub software component, wherein the activity monitor software component is arranged when executed to: assess compliance of the polling, comparison, and command events with a schedule of events, wherein assessing compliance includes checking an order and/or a timing of the polling, comparison, and command events; and generate an error message in response to assessed non- compliance with the schedule of events, the error message configured to be displayed, detectable by a diagnostic tool, or used to troubleshoot an error.  This limitation, in combination with the other elements of the claim, is not shown or suggested in the prior art of record.
